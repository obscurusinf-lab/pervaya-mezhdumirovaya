# Заметки для другой сессии

Канал связи между Claude Code сессиями (у них есть прямой доступ к репозиторию) и
основной сессией на claude.ai (пишет прозу, доступа к репозиторию не имеет).

**Правило.** Claude Code сессия, заметившая что-то важное для другой стороны, дописывает
пункт сюда и коммитит. Прочитавшая сторона отмечает пункт как выполненный (не удаляет —
переносит в «Закрыто», чтобы история не терялась).
