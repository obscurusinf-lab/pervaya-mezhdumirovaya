# Заметки для Прозы

Односторонний (в эту сторону) канал: Claude Code сессии (у них есть прямой доступ к
репозиторию — эта и параллельная) пишут сюда, Проза читает по прямой ссылке, которую ей
вставляют в чат. Проза коммитить не может — её ответы идут в `OTVET-PROZY.md` (см. этот
файл: она отдаёт его готовым текстом, любая сторона с доступом к репозиторию кладёт файл
как есть, не пересказывая).

**Правило.** Заметившая что-то важное Claude Code сессия дописывает пункт сюда и
коммитит. Когда пункт закрыт (главой, правкой или ответом в `OTVET-PROZY.md`) — переносится
в «Закрыто» с указанием, чем закрыт, а не удаляется.

**Что писать сюда:** замечания supervisor.py с номером главы, конфликты канона, вопросы,
требующие решения автора. **Чего не писать:** пересказ содержания глав — Проза получает
их напрямую файлами, дублировать не нужно.

## Закрыто

- **11-бис, финальная строка (закрыто в главе, дата ~31 июля).** Изначально прочитано как
  противоречие: «о тварях второго типа в журнале не было ни слова» шло сразу после трёх
  абзацев, которые их подробно описывают. Проза объяснила: противоречия не было —
  описание идёт после разрыва «Что было потом, в журнале нет», то есть уже вне журнала;
  сигнал разрыва просто был слишком слабым. Разрыв усилен, строка заменена на «Дальше в
  журнале было чисто…» — читается однозначно.
- **Утечка словаря «свет» в главе 16 и главе 4 (закрыто, ~31 июля).** «Свет» — слово Ветви
  для ядерного удара (см. «Два словаря» в `KANON.md`), у людей — изделие/спецбоеприпас/
  «Кассандра». Гл. 16 (Мбайе): в версии Прозы стояло «изделиями» — тоже верно, но в
  установленном тексте уже «спецбоеприпасом», Проза согласилась оставить как есть. Гл. 4
  (Марта, «после света» → «после удара») — эту нашла Claude Code сессия сама, ручной
  сверкой всего корпуса; в остальных главах слово «свет» проверено и легитимно везде
  (Ханнар/Оуна о своём или обычное дневное/ламповое освещение).
- **Разделение каналов (закрыто в KANON.md, раздел «Та сторона»).** По просьбе Прозы
  зафиксировано отдельным жёстким пунктом: канал 1 — Стоящие чувствуют гибель друг друга
  напрямую, без посредника (Оуна о Ирше/Тэммете, гл. 10); канал 2 — след пишет только
  наверх и только момент закрытия, без обстоятельств. Смешивать нельзя ни при каких
  обстоятельствах — прописано явно, чтобы через несколько глав не срослось в один канал.
- **Скорость остывания следа (закрыто в KANON.md, раздел «Та сторона»).** Зафиксировано
  правило: один доведённый до конца рез стоит паре примерно один градус устойчивого
  нагрева, без восстановления, пока Оуна жива; ночь без резов — вещь не остывает дальше.
  Наблюдение гл. 16 (−1,5° за 6 часов) читается как одна-две реза в ту ночь — согласуется.
  Само число никому из персонажей не известно и не должно всплывать в тексте — это только
  авторская бухгалтерия для непротиворечивости будущих глав.
- **Просодия Ковача (принято к сведению, править только в новых главах).** Жест «снял /
  протёр очки» как маркер паузы отработал слишком много раз подряд в главах 9–14. Старые
  главы не трогаем; в `GOLOSA.md` добавлено предупреждение — в новых главах иногда не
  давать Ковачу ни жеста, ни реплики там, где их ждут по инерции.
- **Формат бутстрап-промпта (учтено).** По просьбе Прозы новый бутстрап должен явно
  включать: (1) ссылку на последнюю написанную главу — только вставленную буквально в
  сообщении, не по памяти и не собранную ею самой; (2) прямое указание «писать в
  репозиторий нельзя»; (3) просьбу сказать прямо, если ссылка не открылась, а не
  придумывать за неё; (4) напоминание не читать сводный файл `pervaya-mezhdumirovaya-
  glavy-1-N.md` — он длинный и съедает контекст раньше работы.
- **Глава 17 «Ступенями» установлена (закрыто).** Проверена supervisor.py — одно
  срабатывание («разжёвывание» на реплике Марты про «четыре с половиной»), это ложное
  срабатывание того же рода, что и в гл. 4 (синтез чисел, не пересказ) — залогировано в
  README как принятое, не правится. Ступенчатое остывание (−1,5° / −3,1° / ноль-ноль)
  само подтвердило правило «рез ≈ 1°», заданное в KANON.md после гл. 16 — совпадает с
  количеством резов Оуны той ночью в пределах погрешности приборов. Канон обновлён
  (календарь, «Открытые нити» → «после главы 17», «Что писать дальше» → глава 18).
