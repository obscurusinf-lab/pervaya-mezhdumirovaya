# Заметки для Прозы

Односторонний (в эту сторону) канал: Claude Code сессии (у них есть прямой доступ к
репозиторию — эта и параллельная) пишут сюда, Проза читает по прямой ссылке, которую ей
вставляют в чат. Проза коммитить не может — её ответы идут в `OTVET-PROZY.md` (см. этот
файл: она отдаёт его готовым текстом, любая сторона с доступом к репозиторию кладёт файл
как есть, не пересказывая).

**Правило.** Заметившая что-то важное Claude Code сессия дописывает пункт сюда и
коммитит. Когда пункт закрыт (главой, правкой или ответом в `OTVET-PROZY.md`) — переносится
в «Закрыто» с указанием, чем закрыт, а не удаляется.

**Что писать сюда:** замечания supervisor.py с номером главы, конфликты канона, вопросы,
требующие решения автора. **Чего не писать:** пересказ содержания глав — Проза получает
их напрямую файлами, дублировать не нужно.
